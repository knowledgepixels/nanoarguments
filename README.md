# Nanoarguments: Discourse and Evidence Graphs for Decentralized Scholarly Communication

This repository contains documentation and related materials for the Nanoarguments project.

## About the project

This project aims to build a framework and tools for creating and viewing
professional discourse, initially focusing on scientific discussions and
evidence, with pilot demonstrations in early adopter communities, providing a
reusable, interoperable infrastructure for transparent, persistent discourse.

Researchers, open science communities, standard groups, and developers can
follow and contribute to a global discourse and evidence graph that is
conceptually integrated and browsable as a unified resource, but technically
federated and distributed, based on the existing nanopublication network with
open APIs and protocols.

Nanopublications are small, self-contained Linked Data snippets representing
claims, evidence, and issues with precise provenance and authorship, ensuring
persistence and verifiable records.

The project will deliver a discourse framework integrated with standards, extend
the Nanodash interface to facilitate browsing and contributions, and integrate
nanopublications with tools such as dokieli's notifications, annotations, and
activity feeds, as well as ActivityPub via a connector for bidirectional
interaction with decentralized platforms.
